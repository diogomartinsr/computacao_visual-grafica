# Blog — Computação Visual

Blog acadêmico desenvolvido para registrar conteúdos e reflexões da disciplina de Computação Visual.

## Estrutura

- `index.html` — Página inicial com as aulas 1 a 8
- `aula1.html` — Conceitos gerais e reflexão inicial
- `aula2.html` — Erros em imagens geradas por Inteligência Artificial
- `style.css` — Estilos do projeto

As aulas 3 a 8 estão reservadas para os próximos conteúdos.

## Como executar

Basta abrir o arquivo `index.html` no navegador.

## Publicação no GitHub Pages

Depois de enviar os arquivos para o GitHub:

1. Abra **Settings** do repositório.
2. Entre em **Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha a branch `main` e a pasta `/ (root)`.
5. Salve.

O GitHub disponibilizará um endereço público para o blog.
